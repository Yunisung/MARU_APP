# 크레디탑 관리자 프로그램

## 소개 (Description)
- 건흥페이먼츠 결제 솔루션 크레디탑 관리자 프로그램
- 거래내역 및 정산내역 확인가능
- 가맹점 및 거래 관리

## 기술 스택 (Tech Stack)
- Language : Java
- Core Framework : Spring Boot
- Web Framework : Spring Web MVC 4.2.9
- Application Sever : Embedded Tomcat 8.x
- DB : MariaDB 1.5.5
- Connection Pool : HikariCP 2.7.9
- Build Tool : Apache Ant
- IDE : IntelliJ, Eclipse
- Logging : Logback
